Política de privacidad — Historias de Las Lomitas

Última actualización: 10 de octubre de 2026.

La aplicación "Historias de Las Lomitas" es una herramienta interna que usa únicamente el propietario del canal de YouTube Historias de Las Lomitas para subir sus propios vídeos, editar sus títulos, descripciones, miniaturas y subtítulos, y consultar las estadísticas de su canal.

Datos a los que accede

Mediante los Servicios de API de YouTube y con el permiso del propietario, la aplicación accede a los datos del canal del propietario (vídeos, metadatos, subtítulos, comentarios y estadísticas de YouTube Analytics). No accede a datos de otros usuarios ni de otros canales.

Uso, almacenamiento y cesión

Los datos solo se usan para gestionar el propio canal. El token de acceso se guarda localmente en el ordenador del propietario. No se venden, ceden ni comparten datos con terceros.

Esta aplicación usa los Servicios de API de YouTube. Consulta las Condiciones del Servicio de YouTube y la Política de Privacidad de Google. Puedes revocar el acceso en cualquier momento desde la configuración de seguridad de tu cuenta de Google.
